PersonaGuard

Risk signals for synthetic or highly automated accounts

PersonaGuard analyzes linguistic, behavioural and network signals to identify accounts exhibiting characteristics associated with synthetic or highly automated personas.

How it works

You supply account data. The server extracts text, similarity, timing, profile and graph features, then scores them with a trained model or, if none is installed, a labelled demo rule set.

Detection signals

Sentence and phrase regularity, embedding similarity between posts, posting-interval regularity, burst and hour patterns, profile completeness, interaction-graph structure, and Isolation Forest anomaly distance.

Limitations

Output is a probabilistic risk estimate, never proof that someone is fake. Regular schedulers, template users and generic bios are common among humans. Demo mode is unvalidated.

Privacy

Submitted data is processed in memory and not stored by the server. History lives in this browser tab only; “Clear session” removes it. No logins or private platform access are requested; the tool never scrapes.

Analyze an account

Paste account JSON, or upload JSON or a posts CSV (columns text,timestamp). Schema: username, bio, created_at, followers, following, posts[{text,timestamp}], interactions[{source,target,timestamp}].
